# Airbnb-Project

# 🏡 Airbnb Data Analysis & Dashboard

This project provides a comprehensive analysis of Airbnb listings using Python (Jupyter Notebook) and Power BI. It is based on a public Airbnb dataset and offers insights into pricing, availability, reviews, and neighborhood trends.

## 📁 Project Contents

- `Airbnb_Open_Data.csv` — Raw dataset of Airbnb listings.
- `airbnb project.ipynb` — Python notebook for data cleaning, analysis, and visualization.
- `Airbnb Dashboard.pbix` — Power BI report for interactive exploration.
- `Airbnb_Project_Documentation.pdf` — Detailed project summary and improvement suggestions.

## 📊 Key Insights

- **Top neighborhoods** by number of listings.
- **Price distribution** across regions and room types.
- **Review patterns** and listing popularity.
- **Availability trends** throughout the year.
